Get Started

Joan is a small, dynamically typed programming language designed to be simple, expressive, and embeddable. Joan uses a bytecode virtual machine and provides features such as functions, closures, iterators, modules, objects, hash maps, pattern matching, and exception handling.

Joan source files use the .jt extension.

Hello World


puts("Hello, World!")

Running Joan

A Joan program can be executed by passing its source file to the Joan executable. 


$ joan main.jt

Joan can also be used interactively through its REPL. 


$ joan

joan> let name = "Joan"
joan> puts(name)
Joan

Source Files

Joan programs conventionally use the .jt extension. 


project/
├── main.jt
├── config.jt
└── utils.jt

Language Basics

Joan has a compact syntax inspired by modern scripting languages. Variables can be declared with let and constants with const.

Variables


let name = "Raphael"
let age = 25
let score = 98.5

Constants


const pi = 3.14159
const language = "Joan"

Short Declaration

Joan also supports the := declaration syntax. 


name := "Joan"
age := 25

Comments


// This is a comment

let x = 10 // Comments can follow expressions

Operators

Operator Description
+ Addition
- Subtraction
* Multiplication
/ Division
% Modulo
== Equality
!= Inequality
< Less than
> Greater than
<= Less than or equal
>= Greater than or equal

Control Flow

Joan provides conditional expressions, loops, foreach iteration, pattern matching, break, and continue.

If Statements


if age >= 18 {
    puts("Adult")
} elseif age >= 13 {
    puts("Teenager")
} else {
    puts("Child")
}

For Loops

Joan supports C-style for loops. 


for i := 0; i < 10; i += 1 {
    puts(i)
}

Foreach

Collections can be iterated directly using in. 


items := [1, 2, 3, 4, 5]

for item in items {
    puts(item)
}

An index and value can also be unpacked during iteration. 


for index, value in items {
    puts(index)
    puts(value)
}

Break and Continue


for i := 0; i < 100; i += 1 {

    if i == 10 {
        break
    }

    if i % 2 == 0 {
        continue
    }

    puts(i)
}

Match

Joan supports pattern-style branching with match. 


match value {
    1 => puts("one")
    2 => puts("two")
    3 => puts("three")
    else => puts("other")
}

Functions

Functions are first-class values in Joan. They can be assigned to variables, passed as arguments, returned from other functions, and stored inside collections.

Defining Functions


fn add(a, b) {
    return a + b
}

Calling Functions


result := add(10, 20)

puts(result)

Default Arguments


fn greet(name = "World") {
    puts("Hello " + name)
}

greet()
greet("Joan")

Keyword Arguments


fn create_user(name, age, active = true) {
    // ...
}

create_user(
    name = "Joan",
    age = 1,
    active = true
)

Lambda Functions

Small expressions can be represented using lambda syntax. 


square := |x| => x * x

puts(square(5))

Yield

Functions can yield values to create generator-style iteration. 


fn numbers() {
    yield 1
    yield 2
    yield 3
}

Collections

Joan provides arrays, tuples, ranges, and hash maps.

Arrays


numbers := [1, 2, 3, 4, 5]

puts(numbers[0])
puts(numbers[-1])

Tuples


point := (10, 20)

x := point[0]
y := point[1]

Hash Maps


user := {
    "name": "Joan",
    "age": 1,
    "language": "jt"
}

puts(user["name"])

Ranges

Ranges can be created with the .. operator. 


for i in 1..10 {
    puts(i)
}

Types

Joan is dynamically typed. Values are represented internally by Joan objects and may be inspected and manipulated at runtime.

Type Description Example
None Represents the absence of a value. none
Boolean Boolean value. true
Integer Whole number. 42
Float Floating-point number. 3.14
String Text value. "hello"
Character Single character. 'a'
Array Mutable ordered collection. [1, 2, 3]
Tuple Ordered tuple of values. (1, 2)
Range Sequence represented by a range. 1..10
HashMap Key-value collection. {"name": "Joan"}
Function User-defined callable value. fn add(a,b) {}
Iterator Object used to iterate over values. iter
Generator Produces values lazily. yield
Module Imported Joan module. import math
Struct User-defined structured type. struct User {}
Instance Instance of a user-defined type. User{}

Type Construction

Types can be explicitly constructed when required. 


message := string{"hello"}

number := int{"42"}

Modules

Joan modules allow code to be split into reusable source files. Modules can expose functions, variables, types, and other definitions.

Importing a Module


import math

Importing Specific Names

Individual names can be selected from a module. 


import math{sqrt}

Module Example

Suppose math.jt contains: 


fn square(x) {
    return x * x
}

Another file can import the module and use its definitions. 


import math

result := math.square(10)

Error Handling

Joan provides exception handling using try and except.

Try / Except


try {
    result := 10 / 0
} except {
    puts("An error occurred")
}

Runtime Errors

Runtime errors are represented by Joan error objects. Errors can propagate through function calls until they are handled by an appropriate exception handler. 


fn divide(a, b) {
    return a / b
}

try {
    divide(10, 0)
} except {
    puts("division failed")
}

Built-in Functions

Joan provides built-in functions for common operations.

Function Description
len() Returns the length of a supported value.
puts() Writes a value to standard output.
gets() Reads input from standard input.
hasattr() Checks whether an object has an attribute.
sleep() Pauses execution for a specified duration.

Object Methods

Built-in objects expose methods appropriate to their type. 


name := "Joan"

name.starts("Jo")
name.ends("an")

Arrays and hash maps also provide collection-oriented methods. 


items := []

items.push(10)
items.push(20)

user := {}

user.push("name", "Joan")

Command Line

The Joan executable can be used to run programs or start an interactive session.

Run a File


$ joan main.jt

Run Source Directly

Joan can also execute source supplied directly through the command line. 


$ joan -c 'puts("Hello from Joan")'

REPL


$ joan

joan> 1 + 2
3

joan> let x = 20
joan> x * 2
40

Runtime

Joan is implemented as a compiler and virtual machine. Source code is parsed into an abstract syntax tree, compiled into bytecode, and executed by the Joan virtual machine.

Runtime Objects

Virtual Machine

The Joan VM executes bytecode instructions using a stack-based execution model. Each execution context maintains an instruction pointer, stack, environment, and associated runtime state.

Objects

Joan values are represented by runtime objects. The object system supports primitive values, collections, functions, iterators, modules, structures, instances, methods, native functions, ranges, and errors.

Garbage Collection

Runtime objects are managed by Joan's garbage collector. Objects can be marked during collection and reclaimed when they are no longer reachable.

Embedding Joan

Joan exposes a C API that allows the language runtime to be embedded into native applications. 


Jn_State* state = Jn_get_state();

Jn_exec_program(
    state,
    "puts(\"Hello from embedded Joan\")"
);

Native C functions can also be registered with the Joan runtime. 


Jn_register_fn(
    state,
    "my_function",
    my_function
);

Issues

Joan is actively developed. Some language features and runtime APIs may change between releases.

Reporting an Issue

When reporting a bug, include the Joan version, operating system, source code that reproduces the problem, and the error output. 


Joan version: 0.7.8
Platform: Windows / Linux / macOS

Example:

fn main() {
    // minimal reproduction
}

Development

Joan's source code contains the lexer, parser, compiler, bytecode emitter, virtual machine, object system, garbage collector, standard library, and C embedding API.

Contributions, bug reports, language proposals, and improvements are welcome through the project's GitHub repository.
