🧩Simplicity

Joan has been designed for simplicity and readability, making development faster and easier for beginners and experienced developers alike.

⚙Lightweight Virtual Machine

A compact and efficient virture machine executes Joan bytecode with low memory usage and fast startup times.

♻Automatic Memory Management

A modern garbage collector automatically manages memory allocation and cleanup, allowing developers to focus on application logic.

🧠Dynamic Object System

A flexible object model supports integers, strings, floats, arrays, hashmaps, and user-defined types through a unified runtime.

🔧Extensible Native API

Easily integrate C liberies and native code, allowing developers to extend the language with high-performance.
